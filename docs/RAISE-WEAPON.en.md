# Animation mod-site release copy (English)

## Title

Raise Weapon: Aim at Yourself — Animation Mod

Bilingual title: Raise Weapon: Aim at Yourself / 舉槍瞄準自己

## Short description

Replaces the Raise Weapon emote with a self-aim pose. Animation only; pair separately with Projectile Collision Filter for P-11 self-hit healing.

## Body

### Turn Raise Weapon into a self-aim pose

This mod replaces the **Raise Weapon** emote animation so your character points the weapon toward themselves while playing it. Equip that emote and activate it using your own emote binding.

**Known issue: playing this emote while sprinting and shooting can cause a softlock. If it happens, cancel sprinting or switch weapons. This existing issue remains listed and is not marked fixed.**

### What this package provides

- A replacement animation and aiming pose for the Raise Weapon emote.
- Your own key bindings remain in use; no particular default key is assumed.
- Arsenal manages enablement and disabling.
- The animation package does not modify projectile collision, healing amount, health or other damage effects, and does not make P-11 work on its owner by itself.

An animation change does not establish self-hit collision. For healing, install a compatible projectile self-hit mod separately and land an actual fired P-11 dart on the character.

### Install and use

1. Close the game and download the existing animation package from this page.
2. Import the original package into Arsenal. If another mod replaces the same Raise Weapon animation, disable one of them to avoid competing replacements of the same resource.
3. Enable this animation mod and redeploy.
4. Launch the game and equip the **Raise Weapon** emote.
5. Activate it using your own emote controls. Avoid combining sprinting, shooting and the emote; if you become stuck, cancel sprinting or switch weapons.
6. To disable it or change animation packages, close the game first, make the change in Arsenal and redeploy.

If the animation has not changed, confirm that Raise Weapon is equipped, then check whether another mod overrides the same animation resource. Use the controls configured in your game; no fixed key is required.

### Pairing with P-11 self-hit healing

Recommended separate companion: [Projectile Collision Filter / P-11 self-healing](https://ayakamods.com/mods/p-11-self-hit-healing-p-11-%E6%B2%BB%E7%99%82%E6%89%8B%E6%A7%8D%E8%87%AA%E7%99%82.4166/). Start with its **僅治療手槍 — P-11 only** choice.

Manage the two mods independently. This package supplies the emote pose; Projectile Collision Filter allows qualifying local P-11 darts to collide with their owner. Healing still requires an actual dart hit and the game's native logic, with manual aiming and firing retained. Follow the self-hit mod's own page for loader, game-version and installation requirements.

The companion is not bundled with this animation package. Teammate homing is also a separate mod; this package adds no target lock or automatic firing.
