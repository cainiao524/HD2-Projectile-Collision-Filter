# P-11 Self-Hit — 原生自命中治療

**讓治療手槍真正射出的飛鏢能夠命中自己的角色，觸發原本的治療效果。**
適合希望 P-11 同時能服務隊友與自己的玩家。

## 功能

- 只對通過本機玩家、P-11 武器及投射物身份檢查的飛鏢處理。
- 清除單發投射物的來源碰撞排除位元；實際治療仍由遊戲原生邏輯完成。
- 保留原本彈藥、射速、治療量與效果；不直接補寫血量／體力。
- 純資料修改，沒有原生 hook、執行碼補丁或共享武器定義覆寫。
- 標準 Bingus Shared Loader API 1 addon，獨立 Lua 資源與 Arsenal 開關。

本模組讓自己的飛鏢能夠命中自己；治療仍需真正射出並命中角色。
它不會自動把飛鏢導向自己。

## 安裝與移除

1. 完整退出遊戲，單獨安裝 [Bingus Shared Loader](https://github.com/CowboyBingus/BingusSharedLoader)。
2. 在 Arsenal 匯入自療 ZIP，停用舊自療 hook、重複版本及研究採集包。
3. 啟用本模組和 loader，按 loader 的優先順序說明部署後啟動遊戲。
4. 停用時關閉遊戲、在 Arsenal 取消本項目，再重新部署。

不需要 F6 設定面板、不需要 F8 採集。遊戲更新導致版本不符時會停止資料修改。
後續維修需要確認新版資料布局，不應只替換雜湊以跳過保護。
