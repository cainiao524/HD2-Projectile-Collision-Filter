# 自命中擴展候選 0.1.2

三個擴展範圍：pistols（手槍排除霰彈）、native_no_shotguns（廣域排除霰彈）、native_weapons（廣域包含霰彈）。每個 ZIP 內建原 P-11 0.2.1，通常使用 P11-Enhanced 四選一包選擇；同時只部署一個方案。

排除版先跳過已知霰彈、表內所有多彈丸及表外類型，再查來源／武器／附件。排除集合共 38 個類型，含霰彈獨頭變體；其他多彈丸机制也可能被排除。Source/projectile-exclusions.json 保存來源與分類依據。這是離線資料分類，不能當成目前遊戲所有武器或效能的實測。

包含版保留每顆合格投射物的完整寫前重檢，多彈丸可能造成卡頓；廣域不代表所有射線、光束、近戰、爆炸或 entity 投射物均受支援。

擴展始終排除 P-11 資源與 type 318，由同包未改的原 P-11 addon 處理。通過本機來源、有效武器登記、附件所有者、定義與原旗標檢查後，僅清除非執行私人記憶體中的 0x20，寫前重檢、寫後讀回。沒有 native hook 或角色生命／體力／武器傷害／彈藥寫入。每次更新重新定位；快取僅共用同次更新的查詢，不授權寫入。

只接受 build 25480438 的指定 DLL/EXE 雜湊，Bingus Shared Loader v17 / API 1 / internal 16。未知版本停止。關閉遊戲後在 Arsenal 選擇或停用並重新部署。不要同開舊版。

日誌 WeaponSelfHitCandidate.log 中 ENABLED 只表示版本檢查通過，FIRST DATA WRITE READ BACK 不是命中或傷害成功證據。所有擴展及新封裝共存仍未經遊戲內完整驗證。保留 2048 槽位掃描，無零開銷承諾。來源、排除表、profile 及驗證記錄均隨包附上。
