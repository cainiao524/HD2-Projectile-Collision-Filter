## 0.1.1：篩選及查詢成本

新增 45 個 mock 斷言，檢查多彈丸共用查詢、先排除非手槍、不跨更新沿用正／負判定、相同彈種的不同來源武器、不同定義，以及快取建立後逐一修改 23 個共同依賴欄位的拒絕寫入。共 153 個候選 Lua 斷言（原核心 17、篩選 45、入口 7、與 P-11 回呼组合 84）。

benchmark_reads.py 比較合成記憶體讀取次數，包含 mock writer 的依賴重檢，但不包含所有 Windows API 呼叫。32 顆自己主武器的彈丸：手槍模式 427 → 50；廣域模式 1,515 → 985。這不是 FPS、遊戲主執行緒耗時或零卡頓證據。來源相同不免除逐顆寫前重檢。
